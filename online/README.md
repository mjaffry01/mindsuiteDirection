# Online version

`mindsuite-app.html` is the same MindSuite app as a single file for claude.ai:
the 365-day plan, the sales and marketing toolkit, and the department
definitions and KPIs.

To publish it under another Claude account: sign in to that account, start a
chat, upload this file and ask Claude to "publish this file as an artifact; it
uses the db and user capabilities for shared data". The new link belongs to
that account.

The Node.js version in the folder above does the same things on your own
server. The two versions keep separate data.
